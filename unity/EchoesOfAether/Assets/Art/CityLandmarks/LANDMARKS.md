# City landmarks & district buildings kit (Echoes of Aether)

Generated by `blender/city_landmarks` (Blender 5.2 headless + numpy; everything procedural, no AI images, no photos). Source of truth: `manifest.json` next to this file.

67 assets, 7 kit materials, textures 37.2 MB, FBX 25.8 MB.

## Rebuild

```
cd blender/city_landmarks
python3 lmmats.py                      # lm_* tiling materials (2K, macro-varied)
python3 atlas_build.py --preview        # building_trim_atlas + emit_building_atlas (env kit textures)
Blender -b --factory-startup --python rebuild_env_buildings.py && python3 patch_env_manifest.py   # env Building_* -> <= 8 mats
Blender -b --factory-startup --python build.py -- [names/globs]   # landmarks, district buildings, plaza blocks, modules
python3 write_manifest.py
Blender -b --factory-startup --python render_lm.py -- previews/sheet.png 'LM_*'   # Cycles previews
```

## Conventions

- **units**: metres; FBX exported with apply_scale_options=FBX_SCALE_ALL, bake_space_transform=True, axis_forward=-Z, axis_up=Y -> import at scale 1, identity rotation
- **axes**: Unity Y up, asset FRONT = +Z (Blender -Y). Prototype mapping: Unity = (-x, y, z); a yaw of 0 faces prototype +z (south).
- **pivot**: base-centre of the building MASS for landmarks / buildings / plaza blocks; roof sets: base-centre on the roof slab; facade pieces ('wall-base'): centre of the bottom edge on the host wall plane, projecting toward +Z
- **lods**: <Name>_LOD0/1/2 siblings -> LODGroup. LOD1 ~25-40% (openings with reveals, big props), LOD2 ~3-6% (flat walls + flush lit window panes so the night silhouette survives). lodTransitions: one value per LOD, last = cull (0 = never, the city culler handles it).
- **materials**: Max 8 slots per asset: env-kit tiling materials + this kit's lm_* materials + the shared building atlases (building_trim_atlas, emit_building_atlas; defined in the Environment manifest) + env holo/glass.
- **uv0**: metres for tiling materials (world-scale, explicit facade UVs: U along the wall, V = height); atlas faces use 0..1 atlas UVs.
- **colliders**: box colliders in Unity local space (centre/size). Landmarks carry their own colliders; plaza blocks / kit buildings: the zone code keeps its mass collider, the manifest box is the mass.
- **textures**: BaseColor sRGB, Normal OpenGL (Unity convention), MaskMap linear RGBA (R metallic, G AO, B height, A smoothness); Occlusion points at the MaskMap (URP samples .g).
